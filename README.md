## Screw って？

サイトを開いたとき、中身が表示されるまでの一瞬の「間」。そこに、あなたらしさを添えてみませんか？

Screw は、WordPress サイトにオリジナルのローディング画面を追加するプラグインです。お好みの画像やロゴを使って、読み込み中の画面をあなたのサイトの一部に変えることができます。

難しい設定は必要ありません。画像を選んで、好みの演出を決めるだけ。サイトの「第一印象」を、もっと自分らしくデザインしましょう。

---

## Screw でできること

1. **ローディング画像の設定** — メディアライブラリから好きな画像を選んで、読み込み画面の中心に表示できます。サイズも自由に調整可能です。
2. **エフェクト** — ローディング画面に動きを加えます。
   - **ワイプ** — 上下左右の 4 方向から選べるスムーズなアニメーションです。
   - **プログレスバー** — 読み込みの進捗をリアルタイムで表示します。色も自由にカスタマイズできます。
   - **スピナー** — シンプルな回転リングを表示します。色のカスタマイズが可能です。
3. **背景のカスタマイズ** — 単色の背景はもちろん、画像をアップロードしてフルスクリーンの背景にすることもできます。
4. **長時間ローダーテキスト** — ローダーが長時間表示された場合に、カスタマイズ可能なテキストメッセージを表示できます。
5. **プレビュー機能** — 公開前に新しいタブでローディング画面を確認できます。

---

## 使いかたの 3 ステップ

専門的な知識がなくても大丈夫。

1. **プラグインを入れる** — [Releases](https://github.com/villyoshioka/Screw/releases) ページから ZIP ファイルをダウンロード。WordPress の「プラグイン」画面からアップロードして、有効化するだけです。
2. **画像を選ぶ** — メニューに新しく現れる「Screw」を開き、ローディングに使いたい画像を選びます。
3. **演出を決める** — ワイプの方向やプログレスバー、スピナー、背景などをお好みで設定して「設定を保存」をクリック。

---

## プライバシーについて

このプラグインは、あなたのサイトにローディング画面を添えるためだけに存在します。あなたのデータを勝手に集めたり、こっそり追跡したりすることは一切ありません。
